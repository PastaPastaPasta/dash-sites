Ask Dash Platform directly

Your browser already made these checks before it showed you this page. This button makes them again from inside the page, with a separate copy of the SDK.

The check downloads the Dash SDK (about 9 MB, from the jsDelivr CDN) and connects to Dash Platform nodes from this tab. It proves who owns the name, proves the site record, reads every file from the network, and compares each one with what you were served.
