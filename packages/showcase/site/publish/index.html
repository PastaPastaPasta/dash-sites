Publish your own

You need a Dash Platform identity that owns a name and has a little credit. The builder at dash.site/new does the rest in your browser.

  1. Sign in

    Choose Sign in with DashPay and scan the QR code with the DashPay app (More, Tools, Connections, Scan QR), then approve. On a phone, the button under the code opens the wallet instead. The wallet gives the page a key that can only write Dash Sites documents, with a spending limit and an end date you set when you approve. The wallet's own keys never leave it. You need DashPay for Android 11.9.2 or later, or Dash Wallet for iOS 9.1.4 or later.

    Or choose Sign in with a private key: an identity id or name and an authentication key, or an identity file. The key stays in the page.

  2. Pick a name you own

    A DashPay sign-in cannot register names, because its key is limited to Dash Sites. Register one in the wallet, or sign in with a key. Names are 3 to 63 letters, digits and hyphens. Type one to see whether it is free or already has a site.

  3. Build or upload

    Write a page in the builder's editor, or upload a folder or zip of a site you already have.

  4. Publish, fee first

    You see the exact fee before anything is sent. Storage is paid once, when you publish, at about 0.3 DASH per megabyte. Text and code are compressed first.
