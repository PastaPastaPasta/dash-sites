Publish your own

You need a Dash Platform identity with a little credit. The builder does the rest in your browser, and your key never leaves it.

  1. Pick a name

    Names are 3 to 63 letters, digits and hyphens. Type one to see whether it is free.

  2. Know the cost

    Storage is paid once, when you publish, at about 0.3 DASH per megabyte. Text and code are compressed first.

    0.075 DASH

  3. Publish

    Write a page with the builder's editor, or upload a folder or zip of a site you already have. You will see the exact fee before anything is sent.

    Open the builder Get the extension

    Prefer a terminal? The same publisher is a command:

    dash-sites publish ./my-site --name alice
