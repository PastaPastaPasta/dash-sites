This website is a stack of documents

Every page, font and script of built4.dash is stored on Dash Platform, a network run by thousands of masternodes, under a name its owner controls with a key. There is no hosting account, no domain registrar and no server to keep running.

What is different here

The name is the account

built4.dash is a Dash Platform name owned by an identity. Whoever holds that identity's key decides what the name shows. When a name changes hands, the previous owner's site stops being served.

The files are on the network

Files are cut into pieces of up to 14.7 KB and stored as documents, each addressed by its SHA-256 hash. You pay a storage fee once, when you publish. There is no monthly bill.

You can check what you were served

Dash Platform answers with cryptographic proofs, so a reader does not have to trust the node it asked. Your own browser checks them: dash.site only sends the static page that does it. Run the check yourself.

Put a site on your own name

Write a page in the builder or upload a folder. A site the size of this one costs a few hundredths of a DASH to store.
